## Eobsetric - Σύστημα Προσομοίωσης Μαιευτικής Κλινικής

Το Eobsetric είναι ένα ολοκληρωμένο, αντικειμενοστραφές σύστημα προσομοίωσης
(Simulation System) σε περιβάλλον Java, σχεδιασμένο για τη μοντελοποίηση, τον
ψηφιακό μετασχηματισμό και τη διαχείριση των καθημερινών ροών εργασίας μιας
σύγχρονης μαιευτικής κλινικής. Το project αναπτύχθηκε και παραμετροποιήθηκε πλήρως με χρήση του ολοκληρωμένου περιβάλλοντος ανάπτυξης NetBeans IDE. 


## Περιγραφή του Έργου

Η εφαρμογή προσομοιώνει με ακρίβεια τις λειτουργίες μιας κλινικής, αποτυπώνοντας τις αλληλεπιδράσεις μεταξύ ασθενών, ιατρικού προσωπικού και
διοίκησης. Μέσα από ένα δομημένο σύστημα ρόλων και δικαιωμάτων, το σύστημα
επιτρέπει την αυτοματοποιημένη καταγραφή δεδομένων, τη διαχείριση των
επισκέψεων και την οικονομική παρακολούθηση των ιατρικών πράξεων, δίνοντας
έμφαση στην ορθή αρχιτεκτονική κώδικα και την επεκτασιμότητα.


## Αρχιτεκτονική & Δομή Κώδικα (Domain Model)

Το σύστημα βασίζεται στην Αντικειμενοστραφή Σχεδίαση (Object-Oriented Design)
και αποτελείται από τις ακόλουθες εξειδικευμένες κλάσεις:

username και password. 

⚙ Λειτουργικές Ενότητες & Διαδικασίες

## Οδηγίες Εγκατάστασης & Εκτέλεσης

1. Προαπαιτούμενα ###

Βεβαιωθείτε ότι στον υπολογιστή σας είναι εγκατεστημένα τα παρακάτω: 
# Java Development Kit (JDK): Έκδοση 8 ή νεότερη. 
# NetBeans IDE (ή οποιοδήποτε συμβατό Java IDE που υποστηρίζει Ant
builds). 



2. Λήψη και Εισαγωγή του Project ###

1. Κατεβάστε το αποθετήριο σε μορφή αρχείου .zip
(κουμπί Code -> Download ZIP) ή κάντε clone μέσω τερματικού:
bash

2. git clone https://github.com/Maria-g07/Eobsetric.git

3. Εκκινήστε το NetBeans IDE. 
4. Επιλέξτε File ➔ Open Project. 
5. Πλοηγηθείτε στον κατάλογο που αποθηκεύσατε το project, επιλέξτε τον
φάκελο Eobsetric και πατήστε Open Project. Το NetBeans θα αναγνωρίσει
αυτόματα όλες τις προ-ρυθμισμένες παραμέτρους από τον φάκελο nbproject. 



3. Μεταγλώττιση & Εκτέλεση ###

1. Στο αριστερό πάνελ (Projects), κάντε δεξί κλικ στο όνομα του projectEobsetric. 
2. Επιλέξτε Clean and Build ώστε το εργαλείο Ant να καθαρίσει τυχόν παλιά
αρχεία και να μεταγλωττίσει εκ νέου τον κώδικα. 
3. Μόλις ολοκληρωθεί η διαδικασία με επιτυχία (Build Success), κάντε ξανά
δεξί κλικ στο project και επιλέξτε Run (ή πατήστε το πλήκτρο F6).
